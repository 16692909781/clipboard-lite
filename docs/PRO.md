# Pro Version

Clipboard Lite Core is free and open source. The Pro version is distributed separately as a closed-source plugin and is loaded only after local offline license validation.

## Planned Pro Features

- Encrypted local storage
- Quick phrase templates
- Data import and export
- Paste as plain text
- Advanced clipboard rules

## Notes

- The open-source repository does not include built Pro dynamic libraries.
- Do not commit `pro-plugin.dll`, `libpro-plugin.so`, activation generators, private signing keys, or license production secrets.
- The open core remains local-first and does not make active network requests.
